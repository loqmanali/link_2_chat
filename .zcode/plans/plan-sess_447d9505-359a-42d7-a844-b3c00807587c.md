# ريفاكتور كامل لـ link_2_chat على قواعد flutter-starter-kit

## Context
المشروع (56 ملف Dart / ~14.9k سطر) مبني على flutter_bloc + flutter_hooks + Hive + codegen deps ميتة (build_runner/hive_generator غير مستخدمين)، بدون DI ولا repository layer ولا l10n ولا routing package، وفيه ملف عملاق `settings_screen.dart` (2258 سطر) وsupabase keys مكتوبة hardcode و`/subscription` route مكسور واختبار counter ميت. المطلوب: ريفاكتور كامل **بدون** Hive / Bloc / hooks / أي code generation، بالالتزام بقواعد skill الـ flutter-starter-kit (Riverpod 3 يدوي، go_router، ARB en+ar، طبقات features، architecture guard).

## قرارات معتمدة من المستخدم
- **التخزين**: sqflite بطبقة offline بتاعة الـ starter kit (template_offline) بدل صناديق Hive السبعة
- **اللغات**: ARB إنجليزي + عربي كامل
- **الـ Auth**: نحافظ على النظام المزدوج زي ما هو (حسابات محلية + Supabase) — بس تنتقل للحسابات من Hive لجدول sqflite
- **Git**: commit للحالة الحالية على main ثم branch جديد `refactor/starter-kit`

## المعمارية المستهدفة (من الـ template في ~/.claude/skills/flutter-starter-kit)
```
lib/
├── main.dart / bootstrap.dart
├── app/            app.dart, router.dart, redirect.dart, overrides.dart
├── core/
│   ├── api/         failure.dart (sealed Failure)
│   ├── design/      app_colors (ThemeExtension), app_theme, app_spacing, app_radii, components/
│   ├── environment/ app_environment.dart + env/dev.json + env/prod.json (بدل constants.dart)
│   ├── json/        json_reader.dart (قراءة JSON يدوي — ممنوع codegen)
│   ├── local_db/    local_database.dart + migrations.dart + meta_store.dart + change_watcher.dart (من template_offline)
│   ├── session/     session_providers.dart (Supabase session + current_user_id pref)
│   ├── settings/    app_preferences.dart (theme mode, guest counters...)
│   ├── sync/        sync_service.dart (طابور pending_sync + connectivity + timer) معرّض كـ StreamProvider
│   └── ui/          failure_message.dart, failure_toast.dart
├── features/<f>/{domain, data, application, presentation} + barrel بـ show صريح
└── l10n/            app_en.arb + app_ar.arb + app_localizations (مولّدة بـ gen-l10n ومت COMMITتة)
```
- **State**: Controllers (`...Controller` Notifier) + Actions (`...Action` AsyncNotifier<void> واحد للأوامر) مع `retry: (_, _) => null` — بديل الـ 5 Blocs وكل الـ useState
- **DI**: throw-by-default providers متعملة override في `app/overrides.dart`
- **Routing**: `routerProvider` واحد، redirect نقي قابل للاختبار، كل feature بيصدّر `xPath` + `xRoutes` (بيصلّح باج `/subscription` المكسور)
- **القواعد المفروضة**: ممنوع setState/hooks/banned packages، الـ widget كلاس مش method، `EdgeInsetsDirectional` فقط، ألوان من `context.appColors` بس، كل string في ARB
- **الـ Backend يفضل Supabase**: الطبقات بتاعة الـ kit بتتطبق (data layer بترمي `Failure` + JsonReader للـ rows) من غير Dio — عميل Supabase مباشرة

## مراحل التنفيذ (باستخدام parallel agents)

### المرحلة 0 — Baseline (أنا)
1. commit للتعديلات الموجودة على main ثم `git checkout -b refactor/starter-kit`
2. حذف `lib.zip` القديمة من الجذر

### المرحلة 1 — الأساس (أنا + agent متوازي للـ strings)
1. **سكافولد Core**: نسخ/تكييف من الـ template: bootstrap, app/, core/{json,api,environment,session,settings,design,ui}, local_db من template_offline، `tool/check_architecture.dart` + `check_all.sh` + selftest
2. **pubspec جديد**: حذف flutter_bloc, flutter_hooks, hive, hive_flutter, build_runner, hive_generator, material_ui — إضافة flutter_riverpod ^3.0.0, go_router, sqflite, sqflite_common_ffi, path — إبقاء supabase_flutter, shared_preferences, fl_chart, qr_flutter, flutter_svg, intl_phone_field, url_launcher, share_plus, intl, path_provider, device_info_plus, crypto, uuid — تثبيت connectivity_plus بنسخة صريحة + إبقاء universal_html وpwa_install للويب
3. **Migrations sqflite**: جداول `users` (الحسابات المحلية), `phone_entries`, `user_stats`, `teams` + `team_members`, `api_keys`, `pending_sync` — بارقام متسلسلة
4. **theme**: نقل الألوان الحالية من `app_theme.dart` لـ `AppColors` ThemeExtension بدون material_ui
5. **Agent متوازي (strings)**: يقرأ كل الشاشات الـ 30 ويستخرج كل الـ strings الظاهرة للمستخدم إلى `app_en.arb` + `app_ar.arb` مع keys منظمة (`homeTitle`, `generateLink`...) — أنا أدمجها في l10n.yaml + gen-l10n
6. `tool/check_all.sh` لازم يعدّي على الهيكل الفاضي قبل نهاية المرحلة

### المرحلة 2 — الـ Features بالتوازي (3 agents متزامنين، كل واحد feature folders منفصلة بالكامل)
كل agent يطبّق الـ recipe بتاع الـ kit: domain → data (ترمي Failure، تقرأ بـ JsonReader) → application (Controller/Action providers) → presentation (routes.dart + شاشات) → barrel — باستخدام مفاتيح l10n الجاهزة وfake repositories في الاختبارات:
- **Agent A — auth + subscription**: login/register (الحسابات المحلية على جدول users في sqflite بنفس سلوك الـ sha256 الحالي + مسار Supabase)، subscription_screen + SubscriptionCard
- **Agent B — home + dashboard + history**: HomeBloc→HomeController، link builders كـ domain نقي (whatsapp/telegram/qr)، dashboard بالرسوم البيانية (fl_chart)، history من sqflite + اختبار N+1
- **Agent C — teams + api_keys + settings**: تقسيم الـ god file لـ settings_screen رئيسية + sections كـ widget classes منفصلة (profile, theme/language, behavior, admin sync dialog, delete account)، TeamsBloc→TeamController + team_details، API keys على sqflite

ممنوع عليهم يلمسوا: router.dart, main.dart, main_screen.dart, ARB (مفاتيح جاهزة) — أي ملاحظة تكتبوا في تقريرهم

### المرحلة 3 — الدمج (أنا)
1. `app/router.dart`: جمع كل الـ routes + redirect على الـ session + اختبار `redirect_test.dart`
2. `main_screen.dart` جديد (ConsumerWidget + bottom nav + IndexedStack)
3. bootstrap/main: Supabase.initialize من AppEnvironment، local_db جوه startup_gate
4. sync service wiring + sync status widgets على StreamProvider
5. **حذف الكود القديم بالكامل** (old main.dart, core/services, features القديمة, widgets القديمة, widget_test.dart الميت)

### المرحلة 4 — التحقق
1. `tool/check_all.sh` = architecture guard + `flutter analyze` + `flutter test` + `dart format --set-exit-if-changed` — لازم كلها PASS
2. `dart run tool/check_architecture_selftest.dart` للتأكد من الـ guard
3. تشغيل فعلي: **Chrome web** (`flutter run -d chrome --dart-define-from-file=env/dev.json`) و**Android emulator** عبر MCP tools — smoke test: guest/login، توليد لينك WhatsApp/Telegram + QR، history، dashboard، teams، API keys، settings، تبديل اللغة عربي/إنجليزي
4. إصلاح أي ملاحظات من agents قبل التسليم
